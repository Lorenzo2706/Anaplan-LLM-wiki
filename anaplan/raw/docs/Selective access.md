Selective access enables workspace administrators to restrict access to lists and list items on a user-by-user basis.

To limit access to specific cell data in modules and dashboard grids, consider [Dynamic Cell Access](https://help.anaplan.com/55ae93e6-5139-4bbf-93f9-c8cb06f68f75) instead.

When you [enable selective access](https://help.anaplan.com/4b9dee80-c7aa-4235-b07e-627e2d0689a2) for a list, **Read** and **Write** columns display in the:

- **Users** tab of the **Users** pane. The columns display for lists on which you've enabled selective access. You can select list items in the columns to assign access to users.
- **Grid View** of the list. The columns display against the list items rows. You can select users to have access to each list item.

By default, no users have access once selective access is enabled. Workspace administrators can open the list to view and amend list items. Other users can't read or write to the list until they're [assigned access](https://help.anaplan.com/0cf05fba-6b47-40be-82d8-a0e6fc35599e).

Selective access can also be updated by [importing into a list](https://help.anaplan.com/4ebabad1-072e-4850-8720-ea94cd3b1f75) or the users list. If you import a permission value of "None" for a list, this removes any current selective access that a user has for the list.

**Note:** Your access rights to both the source and target model, and your workspace administrator status, control whether selective access applies to [model-to-model imports](https://help.anaplan.com/fb66fc34-5e93-4f8f-8d82-3e13da73f51a).
