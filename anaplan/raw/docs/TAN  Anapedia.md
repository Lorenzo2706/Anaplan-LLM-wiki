This function can be useful to measure the rate of change between consecutive periods in a rolling trend analysis.

`TAN(Angle)`

| **Argument** | **Data type** | **Description** |
| --- | --- | --- |
| Angle | Number | The angle in radians for which you want to calculate the tangent.  Use the `TORADIANS()` function to convert degrees to radians. |

The `TAN()` function returns a numeric value. But, it becomes undefined at odd multiples of π/2, such as ±π/2, ±3π/2, and others, where the function approaches infinity.

This function is only available in the Polaris Calculation Engine.

`TAN(PI() / 4)`

Returns NaN when *Angle* is NaN.

[TAN](https://support.microsoft.com/en-gb/office/tan-function-08851a40-179f-4052-b789-d7f699447401)

| **Formula** | **Result** |
| --- | --- |
| `TAN(0.785)` | 0.9992 |
| `TAN(45 * PI() / 180)` | 1 |
| `TAN(TORADIANS(45))` | 1 |
