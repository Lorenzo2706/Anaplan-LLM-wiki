This section covers the various sections for import and exports, as well as best practices when building and managing data hubs.

Imports enable you to work with data from external sources in Anaplan and to keep your data consistent across your workspace. You can import data model from a flat file, or from one Anaplan model into another.

Workspace administrators can set up exports to allow the use of data from Anaplan models in external systems.

A data hub allows you to synchronize master data across apps via pre-built imports and standardize the structure and naming of lists across use cases.
