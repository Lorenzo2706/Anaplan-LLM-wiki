Access drivers are line items with Boolean data types. Before you create access drivers, consider these recommendations.

Store access drivers in dedicated access driver modules named according to their dimensions. For example, *SYS01 Access Drivers - Time* or *SYS02 Access Drivers - Cities, Time*.

An access driver module does not have to contain all the dimensions of the target module. For example, if the target module has *Customer*, *Product*, and Time dimensions, and you want to make months read-only, create an access driver module with the Time dimension only.

Use a dedicated [functional area](https://help.anaplan.com/8e318b56-7758-406b-8dda-206c71ec9cf4) to separate access driver modules from other modules in your model.

To control access to cell data by user, enable **Show All Users** when you [configure](https://help.anaplan.com/c18f4a9f-e1f4-4028-b76b-d3f7809e12eb) your access driver module.
