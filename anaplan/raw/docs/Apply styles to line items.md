[Line items](https://help.anaplan.com/line-items-52d76cdd-2571-4400-8f34-b15dd5651b9f "Line items")

If you want to change the appearance of a line item, you can apply styles to it. Use styles to highlight summaries and differentiate data types.

**Note**: Styles only apply to line items on rows, except for the **Summary1** style.

To apply styles to a line item:

1. Select **Modules** in the model settings bar.
2. Select the module that contains the line items you want to apply styles to, then select **Open**.
3. Select **Blueprint** .
4. In the **Style** column, select a style from the list.

The table below describes each available style.

| **Style** | **Formatting changes** |
| --- | --- |
| **Normal** | The default appearance of a line item. The row header indents standard formatting and row height. |
| **Heading1** | - Bolds the row header. - Removes indentation from the row header. - Doubles the height of the row. |
| **Heading2** | - Halves the indentation of the row header. - Increases the height of the row to be one and a half times as tall. |
| **Heading3** | - Italicizes the row header. - Increases the height of the row to be one and a half times as tall. |
| **Summary1** | - Bolds the row header. - Removes indentation from the row header. - Changes the lines at the top and bottom of the row into double-lines.   	(Can also be used to change the lines to the left and right of a column into double-lines) |
| **Summary2** | - Bolds the row header. - Halves the indentation of the row header. Makes the line at the bottom of a row thicker and a darker gray. |
| **Summary3** | - Bolds the row header. - Makes the line at the bottom of a row thicker and a darker gray. |
