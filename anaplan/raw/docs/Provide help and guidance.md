English

Provide users with easy access to help on how to use the model. This can be done by using tooltips or having a page devoted to how the metrics are defined.

Use text and instructions where possible, although keep it simple and don't overwhelm the user with too much jargon.

Use tooltips to help describe the visualizations and give users better information about what they’re seeing.
