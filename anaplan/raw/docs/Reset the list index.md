[General lists](https://help.anaplan.com/general-lists-403a1ed1-ad7b-4ab3-b40c-61dd9d651075 "General lists")

All list items contain a unique list index. Workspace administrators can reset the list index if a list contains a large amount of data, or if a list reaches the maximum index value (999,999,999). A notification displays as the list index number approaches the one billion limit.

Before you can reset the list index to 1, you must remove any list items from the whole list hierarchy.

If your model is in [deployed mode](https://help.anaplan.com/c326f36e-4532-42d7-aab8-d262b63a3f68), you can only reset the list index if the list is a [production list](https://help.anaplan.com/def2aa72-278a-4b85-97fb-d858c1dbbe97).

To reset the list index:

1. Select **General Lists** in the model settings bar.
2. Select a list, then select **Open**.
3. Select **Configure** > **Reset**.

If you want to revert the change, you can [restore your model](https://help.anaplan.com/dc45e7a6-0222-4a2d-891d-f0f3fb1e96b5) to a previous ID in its history.

**Note**: If you [delete list items](https://help.anaplan.com/ca13a66c-6233-48fe-be64-95c69de5192a) from a list, the **Next item index** remains the same. For example, if your list contains five list items, the **Next item index** is 6. If you delete two list items, the **Next item index** remains at 6.
