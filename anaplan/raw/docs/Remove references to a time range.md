Time ranges are referenced by line items contained in a model. If a workspace administrator needs to delete a time range, they must remove all references to it from the model.

Line items may reference a time range. This is contained in the item's **Time Range** attribute. To identify which line items reference your time range:

1. Select **Modules** in the model settings bar, then select the **Line Items** tab.
2. In the line items list, locate the **Time Range** column.
3. Identify which line items reference your time range.
4. Change the assigned time range by selecting the dropdown and selecting another value from the list.  
	A warning displays to alert you to the potential loss of data resulting from this change.
5. Confirm the action by pressing **OK**, or return to the line item list by selecting **Cancel**.

**Note:** If your model contains a large number of line items, we recommend that you first export the line items from the model.

To export all line items:

1. Select **Modules** in the model settings bar, then select the **Line Items** tab
2. Select [**Export**](https://help.anaplan.com/382e8ab6-177c-4df7-8591-73484d164627).  
	The **Export** dialog displays.
	1. In the **File Type** dropdown, select the output file type of your preference.
		2. Select **Run Export** to complete the export, or **Cancel** to return to the line item list.  
		If you run the export, the line items are downloaded to your system in your format of choice.
		3. Use a third-party spreadsheet tool to filter the data and locate the line items that reference your time range.
		4. Use the procedure above to change or remove references to the time range.
