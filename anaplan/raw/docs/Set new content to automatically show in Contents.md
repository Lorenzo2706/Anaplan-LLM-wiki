As a workspace administrator, you can choose for new modules and dashboards to automatically display in a model's **Contents**.

In the **Contents** tab, you can turn **Show New Content** on or off, by [Functional Area](https://help.anaplan.com/8e318b56-7758-406b-8dda-206c71ec9cf4), for each [model role](https://help.anaplan.com/30783e17-b789-4005-b87a-ff15cd3c9044). By default, **Show New Content** is set to **On**.

**Show New Content** is disabled if:

- The model role's access is set to **None** for a module.
- The model role lacks access to module data that displays on a dashboard.

To enable **Show New Content** for a Functional Area, for each role:

1. Select **Show New Access** in the row for the Functional Area to which you want the role to view new content in model **Contents**.  
	A dropdown menu displays the options **Show New Content: On** and **Show New Content: Off**.
2. Select **On** for **Contents** to automatically update and display new items, or **Off** if you want to hide new items.
