As a workspace administrator, you can select which modules and dashboards display in model **Contents** for each model role.

Before you select which content displays in the **Contents** panel of a model, you must [create model roles](https://help.anaplan.com/30783e17-b789-4005-b87a-ff15cd3c9044).

You must [assign module access permissions](https://help.anaplan.com/2a38c1c2-6338-4ac4-9a45-673d23f2a81a) to a model role before you can select content that contains module data to display in the **Contents** panel.

By default, all model contents to which a model role has access will display in model **Contents**.

To select content to display in the **Contents** panel for a role:

1. Navigate to the **Contents** pane.  
	Modules and dashboards display on rows, model roles display on columns.
2. Select the checkbox for any content that you want to display in model **Contents**.  
	Alternatively, deselect the checkbox for any content you want to hide.  
	You can swipe, or click and drag, to select multiple items, then press the space bar to toggle the selection.  
	Modules and dashboards for which the role has no access are disabled.

Note: As a workspace administrator, you can enable [**Show hidden content**](https://help.anaplan.com/2e6f22d8-b0ed-4bc3-899a-4d476aa8cbf4). Users can then choose to view items you deselect from model **Contents**.
