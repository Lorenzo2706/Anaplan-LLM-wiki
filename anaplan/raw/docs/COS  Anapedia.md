This function can be useful to smooth cyclical fluctuations in moving averages.

`COS(Angle)`

| **Argument** | **Data type** | **Description** |
| --- | --- | --- |
| Angle | Number | The angle in radians for which you want to calculate the cosine.  Use the `TORADIANS()` function to convert degrees to radians. |

The `COS()` function returns a numeric value between -1 and 1, inclusive.

This function is only available in the Polaris Calculation Engine.

`COS(PI() / 3)`

Returns NaN when *Angle* is NaN.

[COS](https://support.microsoft.com/en-gb/office/cos-function-0fb808a5-95d6-4553-8148-22aebdce5f05)

| **Formula** | **Result** |
| --- | --- |
| `COS(1.047)` | 0.5002 |
| `COS(60 * PI() / 180)` | 0.5 |
| `COS(TORADIANS(60))` | 0.5 |
