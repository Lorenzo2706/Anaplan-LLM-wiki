[Classic](https://support.anaplan.com/classic-a182c8c4-2e69-437d-8871-78346dc8b1bf "Classic")

Give the view a meaningful name (for example, Export List Members, Filtered View, Export etc.) There's no need to add the module name within the name of the view as the system does that for you.

[Naming Convention](https://help.anaplan.com/name-conventions-aeb0b95e-f7a3-4fe5-81c7-aec9a12f80be)

Filter on a Boolean and only have one filter per dimensional tab. Having multiple filters defined in the same tab can cause performance issues as Anaplan applies the filters sequentially (reads the data and applies the first filter, then applies the second filter to the returned set of the first filter).

Keep the default view as is, no hiding line items, filtering, or conditional formatting.

If you have to nest dimensions, nest the dimensions in order of size (largest to smallest) with the largest being on the outside and the smallest being the inner-most dimension.
