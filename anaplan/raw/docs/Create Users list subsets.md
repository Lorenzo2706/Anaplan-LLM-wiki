[Users list](https://help.anaplan.com/users-list-f3333ecf-a1cc-43d8-af03-ec65c5cdd428 "Users list")

Workspace administrators can create a shorter users list subset from the larger **Users** lists in **General lists**. For example, create a *Sales team* list subset and include two users from the **Users** list.

User list subsets can also be used to [control user access within models](https://help.anaplan.com/8c495688-216e-49c4-aa56-a4b70487e5d7). They can limit access to modules and, indirectly, to pages that access that data in an app, based on the user's membership of the list subset.

To create a User list subset:

1. Select **General lists** in the model settings bar.
2. Select the **Users** list and select **Open**.
3. Select **Subsets** tab.
4. Select **Insert**.
5. Type a name for the subset using proper [naming conventions](https://help.anaplan.com/aeb0b95e-f7a3-4fe5-81c7-aec9a12f80be).
6. To create additional subsets, type each subset's name on a new line.
7. Select from the dropdown where you want the subset to display in the main subset list:
	- **Before**: The subset displays before the subset that's selected in the main subset list.
		- **After**: The subset displays after the subset that's selected in the main subset list.
		- **Start**: The subset displays at the start of the main subset list.
		- **End**: The subset displays at the end of the main subset list.
8. Select **OK**.  
	The subset appears as an additional column in **Grid View**.
9. Select the **Grid View** tab, then select the list items you want to include in the subset.

To reorder list subsets, select **Reorder** then choose from one of the options, or drag the list subset into a new position.

When you create a list subset, it appears in the **Subsets** column in **General Lists**.

**Note:** Workspace administrators can [import users](https://help.anaplan.com/9b0d7f50-886b-4ed6-a591-db85dff4d6e5) from the **Users** pane in a model.
