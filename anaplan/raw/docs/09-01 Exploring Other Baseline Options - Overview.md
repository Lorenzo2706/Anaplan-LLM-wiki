# Exploring Other Baseline Options - Overview

Exercise nine.

Exploring other baseline options.

In this exercise, we will look at the other techniques available for developing a baseline to the demand plan.

Prior to this exercise, we have predominately looked at the statistical forecast, but there are some other ways in which we can actually develop that baseline position.

In particular, what we'll try to do during this exercise is focus on the configuration implications of those techniques.

So what needs to be configured and implemented in order to make them work?

But as part of the exercise, we will also look at what those techniques do, from an end user perspective.

The outcome of this exercise will be that we will have multiple definitions of a baseline plan that the user can choose between.

As we go through this exercise, we will focus on three different baseline approaches.

Firstly, collaborative planning, then rate of sale planning and then finally second tier planning, which is a in, sell thru type of method.

We'll take each of those one at a time.

So first of all we will look at collaborative planning.
