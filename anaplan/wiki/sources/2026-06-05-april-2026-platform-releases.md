# Source: April 2026 Platform Releases & What's Next

Two clippings of the same Anaplan Community post (clipped Jun 1 and Jun 5 respectively — identical content). Community post by @GingerAnderson, published 2026-05-07. Points to the [April 2026 official release notes](https://help.anaplan.com/april-2026-releases-774e1f4a-5510-4736-b4b6-4c1c315b2d19).

## Released in April 2026

From the official release notes (linked, not clipped):

- **Polaris** — unspecified Polaris improvements
- **Security / tenant administration** — CAPTCHA on basic authentication
- **Anaplan XL v2604**

## What's coming next (announced, not yet released at post date)

### CoModeler

| Feature | Description |
|---|---|
| Extended search results | Returns >100 lists or modules in model object searches |
| Cancel in-progress requests | Stop button cleanly aborts without errors |
| Extended modeling capabilities | Iterative NL → model structure implementation (modules, lists, etc.) |
| Create/delete Time Ranges | CoModeler can create/delete Time Ranges in Hyperblock and Polaris models, set name/start/future years/aggregations |
| Update model calendar | CoModeler can edit model calendar directly via NL prompt |

### Disclosure Management

| Feature | Description |
|---|---|
| Large image optimization | Auto-reduces large image sizes in Word/PPT reports for faster Refresh/Combine; can be disabled per doc |
| Co-authoring in Word/PPT | Real-time simultaneous editing in the DM add-in; shows active users |
| UI refresh | Updated UI aligned with Anaplan look and feel |

### User Experience

| Feature | Description |
|---|---|
| Configurable link button targets | Page Builder: open nav/link buttons in same tab or new tab |
| New chart palette & grid theme | Aligned with Anaplan brand colors; upgraded color picker for series |
| Hierarchy Chart filter | Native filtering capability on hierarchy charts |
| Simplified chart creation | Create chart by selecting cells on a grid (no deep model knowledge needed) |

### Workflow

| Feature | Description |
|---|---|
| Standard: Builder undo/redo | Undo/redo for workflow template builders |
| Advanced: Batch approvals | Bulk submission creation; bundled approval emails; reviewer dashboard for pending items |

## Notes for model builders

- **CoModeler Time Range support** is significant for model-building workflows — manual admin steps for creating time ranges will be reducible to NL prompts (Hyperblock + Polaris both covered).
- **CoModeler model calendar editing** closes the last major manual setup gap for model initialization.
- These features were announced but not yet released at the post date (2026-05-07). Verify current availability.
