[Dimensions](https://help.anaplan.com/dimensions-e020c93d-9f3e-4cce-8294-2d34073b302a "Dimensions")

Create list subsets to work with smaller groups of items from a list without creating an entirely new list. You can then use list subset as a dimension in Anaplan.

A list subset enables you to define a smaller, defined selection of items from an existing list. This subset can then be used for specific purposes, such as simplifying models, reducing the size of calculations, or tailoring modules to focus only on relevant items.

For example, the *Employees* list contains all employees at a company. If you want to analyze commissions for employees in the Sales team, create a *Sales Team* list subset from the *Employees* list.

**Note**: You cannot use a list subset in the same module as the list it originates from.

Single list items can belong to multiple list subsets.

Manage your list subsets in **General Lists** in the model settings bar. Open a list, then select **Subsets**. You can create, delete, and reorder list subsets.

Add notes to your list subset in the **Notes** column. The **Referenced in Applies To** and **Referenced as Format** columns display the modules associated with the list subset, and the line items and list properties with the list subset set as the format.

A list subset remains connected to its parent list. Any changes to the parent list have a direct impact. If you add or remove items from a list, then this will reflect on the list subset.
