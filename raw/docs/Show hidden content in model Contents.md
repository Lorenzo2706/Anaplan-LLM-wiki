Workspace administrators can hide modules and dashboards from your model **Contents** if they're not usually relevant to your work. However, they can enable the **Show hidden content** toggle for the **Contents** panel. This enables any user to toggle on hidden contents so they can access these parts of the model.

A workspace administrator hides content from the model Contents panel when they [deselect modules and dashboards from a model role](https://help.anaplan.com/3c5f1e93-205d-4316-9407-6621836cc96f).

To enable the **Show hidden content** toggle, as a workspace administrator:

1. Select **Contents** from **Model settings**, then select the **View** menu.
![A model open to the Contents pane. The View menu is selected in the toolbar and the Enable access to hidden content option displays below it.](https://assets-us-01.kc-usercontent.com/cddce937-cf5a-003a-bfad-78b8fc29ea3f/fd68fbb2-3f1a-410f-adc5-08ee2837817b/contents-pane-enable-content.png)
2. Select **Enable access to hidden content** from the menu.  
	The **Show hidden content** toggle displays at the bottom of the **Contents** panel for all users.

**Note:** You can only ever view content for which your [model role](https://help.anaplan.com/30783e17-b789-4005-b87a-ff15cd3c9044) has access.
