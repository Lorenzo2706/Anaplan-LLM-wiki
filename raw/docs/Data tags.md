Workspace administrators use data tags to group related information in a model. You can search for tagged data by keyword.

For example, if you want to search for a specific list item that appears in multiple lists, [add data tags](https://help.anaplan.com/b8abc628-8d23-454f-9f4c-0a99abb2c49e) to each list. Then, you can [search](https://help.anaplan.com/d21c3efb-b978-431c-83d2-ebad6469f1b4) for the list item across all lists that share the data tag.

Add data tags to:

- [Lists](https://help.anaplan.com/403a1ed1-ad7b-4ab3-b40c-61dd9d651075)
- [List properties](https://help.anaplan.com/da73f852-e39f-4046-bf97-675274ce0947)
- [Modules](https://help.anaplan.com/5d25099d-15ae-426c-ade1-33b658f58b8c)
- [Line items](https://help.anaplan.com/52d76cdd-2571-4400-8f34-b15dd5651b9f)

[Create](https://help.anaplan.com/7d6faa2c-2450-49b8-9928-89f8254d9859), [delete](https://help.anaplan.com/1b5b4023-4ca3-4c2b-b155-304b38861ed4), and reorder data tags in **Data Tags** in the model settings bar.
