[General lists](https://help.anaplan.com/general-lists-403a1ed1-ad7b-4ab3-b40c-61dd9d651075 "General lists")

Before you create a list, it's important you decide what [type of list](https://help.anaplan.com/9e227264-6f53-411b-be7c-68eb578e6322) you want to use.

To create a list:

1. Select **General Lists** in the model settings bar.
2. Select **Insert**.
3. Type a name for the list, see [Name restrictions](https://help.anaplan.com/055f1e28-51fa-4e14-a2a7-8e67aaedc1a0) for more information. Create extra lists by typing each list on a new line.
4. Select **Before** or **After** to add the list before or after an existing list. Select **Start** or **End** to add the list to the start or end of other lists in your model.
5. Select **OK**.

Next, you can [add list items to your list](https://help.anaplan.com/ca13a66c-6233-48fe-be64-95c69de5192a).
