[Time ranges](https://help.anaplan.com/time-ranges-1d28b6e4-184b-4ba2-990c-defcaf65bde6 "Time ranges")

Workspace administrators can create and manage time ranges in the **Time Ranges** tab of the **Time** pane. Access **Time** from the Model settings bar on the left-hand side of your model.

**Note:** The model must be in standard mode to create or edit time ranges. Learn about [model modes and Application Lifecycle Management](https://help.anaplan.com/c326f36e-4532-42d7-aab8-d262b63a3f68).

When naming a time range, you can follow the guidance in [Name conventions](https://help.anaplan.com/aeb0b95e-f7a3-4fe5-81c7-aec9a12f80be).

The Time range name is visible to users when they access [Pivot](https://help.anaplan.com/1dc471a1-7ace-440f-8c3e-d6a430943b3f).

The length of a time range is set in fiscal years. The **Start Period** is the first year in the time range, so a time range that starts in FY2018 with a length of 1 year will span FY2018 only. You can select any year within the system constraints (1981 to 2078) as the start period. If the start period is FY1981, the time range can have a maximum of 98 years; but only one year if the start period is FY2078.
