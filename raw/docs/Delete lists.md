**Warning**: If you delete a list, all associated data is lost.

To delete a list:

1. Select **General Lists** in the model settings bar.
2. Select **Delete**.  
	**Note**: Alternatively, if you want to delete a specific list, first select the list, then select **Delete**.
3. Select the list you want to delete.  
	**Note**: Select **Delete All** to mark all lists for deletion, or select **Keep All** to keep all lists.
4. Select **OK**.
