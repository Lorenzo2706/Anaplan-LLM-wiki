English

Prefix with LIS then a description or the module used in the Line Item Subset. For Line item subsets using multiple modules, use a generic name that best describes its purpose

- [1.08-01 Avoid using emojis](https://support.anaplan.com/avoid-using-emojis-39d5ffdc-b8d3-464e-9f02-890ba002e7ec)

[Good Practice Naming Conventions](https://help.anaplan.com/name-conventions-aeb0b95e-f7a3-4fe5-81c7-aec9a12f80be)

Use Line Item subsets to create different numeric formulae for each version to avoid multiple IF statements.

By default, you should keep summaries turned off on line items using the Collect() function. By having summaries turned on, the system is aggregating data that isn't usually needed.
