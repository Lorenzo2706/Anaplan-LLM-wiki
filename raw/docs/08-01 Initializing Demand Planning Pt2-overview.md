# Initializing Demand Planning Pt2-overview

Exercise eight.

Initializing Demand Planning part two.

In this exercise, we will continue the initialization of the demand planning application by looking at some specific tasks which may need to be carried out.

These include understanding how we might want to set up various user filtering options as part of the project configuration.

Some of the activities associated with managing list items, and then establishing the baseline settings that are going to drive the demand plan, and in particular, how we can use product classification and scenarios to set those baselines.

So the first couple of tasks we will go through relate to management of various lists.

Firstly, the deletion of orphans will come onto what that means in a moment.

And then the creation of empty list placeholders.

Once we've done that we will create some filtering options.

So throughout the application we make use of filters to help the user control what’s being displayed to them on the screen at any point in time.

And then once we set those filters, we will go over to the baseline parameter settings and look at how they are going to be derived based upon scenarios and product classifications.
