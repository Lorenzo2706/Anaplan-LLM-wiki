[Numbered lists](https://help.anaplan.com/numbered-lists-371af0ef-1465-4c4f-9a73-4150f4a6ee95 "Numbered lists")

[Create any lists](https://help.anaplan.com/d16ed36a-0836-44f7-9db5-e7f0477a9213) you might need in **General Lists** in the model settings bar.

For example, you can assign the *Departments* list as the parent of the *#Employees* numbered list. This creates a [composite hierarchy](https://help.anaplan.com/cabf4596-28b5-4849-a028-d2e610905b7d) in your model.

To assign a parent list to a numbered list:

1. Select **General Lists** in the model settings bar.
2. Select a list, then select **Open**.
3. Select **Configure**.
4. Choose a parent list in **Parent Hierarchy**.
