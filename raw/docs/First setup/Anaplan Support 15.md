Use numeric prefixes to signify the order within the process (for example, 1.1 Import Products, 1.2 Import Product details). There's no need to include the technical module name in the description.

[Name Conventions](https://help.anaplan.com/name-conventions-aeb0b95e-f7a3-4fe5-81c7-aec9a12f80be)

Import and Export actions need to be republished if modified or replaced, while Process actions are always consistent with whatever is held within the process, making management easier.

| 5.01-02a Numbered list actions | Actions involving numbered lists (Create, Assign, Copy branch, and Delete branch) cannot be placed in a process. |
| --- | --- |

Critically review the need for user driven actions and consider the effect on user concurrency. Try to use formulas instead. This may require additional modules, but the user experience could be improved as a result.

For imports that are one-offs, delete the import and data source to maintain a clean model.
