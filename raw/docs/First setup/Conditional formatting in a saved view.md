[Conditional formatting](https://help.anaplan.com/conditional-formatting-077b0f84-a07a-47b7-afc3-894792119257 "Conditional formatting")

You can use saved views to display conditional formatting on your pages. Saved views are configured in the source model for a page.

[Learn how to apply conditional formatting](https://help.anaplan.com/b15c1e7c-fb23-4208-ac03-9e820d99ce91) in a source module.

When you build worksheets or cards, you can select a saved view that contains conditional formatting. The conditional formatting from the saved view automatically displays on your worksheets, grid cards, and KPI cards.

When you [design a custom view](https://help.anaplan.com/c439ab45-e31e-4942-9a00-50dec6c8d344), you remove any conditional formatting configured in a source module. To use conditional formatting on a custom view, use the **Card configuration** panel.
