Classic dashboards are not supported for new customers. [Build Apps or Pages](https://help.anaplan.com/3b37cf85-ecbb-48ca-bdbc-add5bd5ab5fa) in the User Experience instead.

Conditional formatting enables you to change the visual style and color of cells dependent on the value in that cell or another cell.

You can:

- [Apply conditional formatting](https://help.anaplan.com/986cb42c-c54c-4b65-ba64-72cf1acfb445) to a grid in a module. You can apply different conditional formatting rules to different line items.
- [Use conditional formatting to validate forms](https://help.anaplan.com/c1e90db0-3e96-4c2b-80a2-008a32a6a65f).

From the **Conditional formatting** dialog box, you can create new rules, edit existing rules, or delete rules.

Conditional formatting on a classic dashboard can be independent of conditional formatting on a module grid. It can be applied to a grid in a dashboard without affecting the original grid.

If there are multiple grids on a classic dashboard based on the same module, you can apply different conditional formatting to each without affecting the module's base settings.
