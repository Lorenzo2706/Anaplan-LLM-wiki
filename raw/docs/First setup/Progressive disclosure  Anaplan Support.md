Present data in digestible chunks. Start simple and expose complexity when needed and not before.

[Top five design best practices for UX: Desktop and mobile](https://community.anaplan.com/t5/Best-Practices/Top-5-Design-Best-Practices-for-UX-Desktop-and-Mobile/ta-p/81648)

Rather than put everything on one page, provide key information and link to another page to provide users with more detail.

On pages showing more granular data, users can do more tasks, such as perform detailed analysis and manipulate and edit the data. Ideally, the driving grid of the page should represent a more detailed view of the previous page.

Use the Additional insights panel to place links that are useful to navigate to and from the current page but aren’t necessary to see on the same page.
