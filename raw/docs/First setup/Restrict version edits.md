[Versions](https://help.anaplan.com/versions-19b4391f-5257-40ee-8dfb-36f0ab426c8f "Versions")

For example, if you set the date range for a version between January and March in FY21, you can only edit the data in that timeframe.

To restrict version edits:

1. Select **Versions** in the model settings bar.
2. Set a date range for your version in the **Edit From** and **Edit To** columns.

**Note**: The date ranges available depend on your model’s **Calendar Type** in **Time** in the model settings bar.
