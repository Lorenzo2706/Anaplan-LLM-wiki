English

Using a well-considered naming convention will organize your Data Orchestrator objects so they're easier to understand, maintain, and build.

Filters on object properties are available on each of the inventory pages. The filter criteria are combined within each property using an OR and across all properties using AND.

If there's any text in the search box, only those objects that have a name containing that text are included.

Filters do not persist after the user exits the page.

Column selections only persist for the current session.
