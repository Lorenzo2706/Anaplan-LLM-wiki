[Picklists](https://help.anaplan.com/picklists-ddeaf549-4699-4e56-be9a-185205c49823 "Picklists")

Picklists are list-formatted line items. Model builders use picklists to provide users with a list of valid values to select from.

For example, if you want to assign new employees to a department, you can create a *Department* line item that is formatted on the *Departments* list.

Create any [lists](https://help.anaplan.com/d16ed36a-0836-44f7-9db5-e7f0477a9213), modules, or line items you might need in **General Lists** and **Modules** in the model settings bar.

**Note**: You cannot use a list-formatted line item as a picklist if it contains a formula.

To set a picklist on a line item:

1. Select **Modules** in the model settings bar, select a module, then select **Open**.
2. Select **Blueprint** .
3. Select a line item, then select the ellipsis (...) in the **Format** column.
4. Select **List** in the **Type** dropdown, then select the list you want to use as a picklist in the **List** dropdown.
5. Select **OK**.
