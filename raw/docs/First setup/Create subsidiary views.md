If you change the dimensions that apply to a line item, a subsidiary view is automatically created. The subsidiary view shows the subset of data and its dimensionality.

To create a [subsidiary view](https://help.anaplan.com/b208ed3b-c958-4a55-94db-c297bc7c95cb):

1. Select **Modules** in the model settings bar.
2. Select a module, then select **Open**.
3. Select **Blueprint**.
4. Use one of the following methods to create a subsidiary view:
	- Select the ellipsis () in the **Applies To** column, then select one or more [lists](https://help.anaplan.com/403a1ed1-ad7b-4ab3-b40c-61dd9d651075) for the line item. When you change the lists that apply to a line item, the dash (-) changes to the list's name. The module's default list displays at the top of the **Applies To** column.
		- Select a time scale or [time range](https://help.anaplan.com/1d28b6e4-184b-4ba2-990c-defcaf65bde6) in the **Time Scale** and **Time Range** columns, respectively.
		- Select a [version](https://help.anaplan.com/19b4391f-5257-40ee-8dfb-36f0ab426c8f) in the **Versions** column.

Select in a line item to open the subsidiary view.

To save a subsidiary view as the module's default view:

1. Open the subsidiary view, then select **View > Save As**.
2. Type a name for the subsidiary view.
3. Select **Save as default view for module**.
4. Select **Save**.

**Warning**: You cannot access line items that are not included in a new default view. To make a line item visible again, select **View** > **Manage Views**, then select **Reset Default View**. Learn more in [Manage views](https://help.anaplan.com/81a92257-5ed0-429a-b4e8-fbde8c05a3fc).
