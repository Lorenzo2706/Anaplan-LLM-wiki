If done well, this makes the content easy to read. It creates a path for the viewer’s eye to follow through the page/screen.

Use a landing page to provide key summary information. This is useful as it orients new users around the model's contents and provides a summary as well as navigation to more detailed pages.

Place summary information first within a category, with detailed data pages afterward. Add instructions guiding and explaining what end users are to do.

Consider what information is most important and place that at the top of the page, for example, key performance indicators (KPIs).
