English

For one-off imports or when source models are no longer required, delete the source model to keep the list tidy.

Remap actions so they have the proper source (this can happen when multiple copies of the Dev model have been created).

By remapping the actions to the correct source (Dev), this will clean up the production model as well as make it easier when changing the source of the actions that are bringing data into the production model.
