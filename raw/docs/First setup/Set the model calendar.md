[Time](https://help.anaplan.com/time-53836b0c-1238-48ef-834a-8728b24f3d8e "Time")

**Warning**: If you make changes to the model calendar, itaffect all [line items](https://help.anaplan.com/52d76cdd-2571-4400-8f34-b15dd5651b9f) and [modules](https://help.anaplan.com/5d25099d-15ae-426c-ade1-33b658f58b8c) that use Time as a [dimension](https://help.anaplan.com/e020c93d-9f3e-4cce-8294-2d34073b302a), or as a list format, and can result in the loss of data.

It's important to configure your model calendar when you first build a model, and before you import data. When you want to plan and analyze data, a chronological time scale is critical.

It's best practice to use the smallest time scale possible. If you add past and future years, the size of the model increases considerably. Use [time ranges](https://help.anaplan.com/1d28b6e4-184b-4ba2-990c-defcaf65bde6) for longer periods.

To set your model calendar, select **Time** in the model settings bar.

First, set the **Calendar Type**. Subsequent settings depend on which calendar type you choose.

| **Calendar type** | **Description** |
| --- | --- |
| [**Calendar Months/Quarters/Years**](https://help.anaplan.com/c9e69e39-0220-46d6-b756-e68e9158bb8c) | All model calendars are set to months, quarters, and years by default. This calendar type allows for monthly timescales. |
| [**Weeks: 4-4-5, 4-5-4, or 5-4-4**](https://help.anaplan.com/150f3b73-8be1-4d95-92fd-24daa46ae869) | Specify a pattern for grouping weeks into months (4-4-5, 4-5-4 or 5-4-4). |
| [**Weeks: General**](https://help.anaplan.com/ba7ab203-412d-48b5-ba4a-bf9695448cff) | Specify the number of weeks from a start date. |
| [**Weeks: 13 4-week Periods**](https://help.anaplan.com/305df19b-36da-481c-bbe5-f07420020ed4) | In a 13-period setup, there are three quarters with three periods, and one quarter with four. Specify which quarters contains three periods and which contains four.  13 four-weekly periods are very common in some countries. For example, banks use this calendar type for payroll periods, instead of calendar months. |

When you set the model calendar, you can further configure the granularity of the model's time scale.

For example, if you include **Quarter Totals** and **Half-Year Totals**, you can [create a line item](https://help.anaplan.com/47f768d6-71fd-497f-8f7d-c4e45adfa12b) that has a time scale of **Day**, **Week**, **Month**, **Quarter**, or **Half-Year** in a [module's Blueprint](https://help.anaplan.com/e7de33be-6345-4ecc-a517-c3265ff6d04a). You cannot configure these settings for the **Weeks: General** calendar.

**Note**: Language settings on your browser control [date formats](https://help.anaplan.com/b84d3bdf-b89d-4ea5-9998-25e235bac2cc). For example, the date 4 December, 2021 might display as `12/04/2021` or `04/12/2021`.
