[Versions](https://help.anaplan.com/versions-19b4391f-5257-40ee-8dfb-36f0ab426c8f "Versions")

**Note**: You cannot delete the Actual version in your model, or a version that exists in a formula with the [SELECT](https://help.anaplan.com/2ca3148d-466e-44bd-830e-7e5cf3ac8d08) function.

To delete a version:

1. Select **Versions** in the model settings bar.
2. Select **Delete**.
3. Select the version you want to delete.  
	Select **Delete All** to mark all versions for deletion, or select **Keep All** to keep all versions.
4. Select **OK**.
