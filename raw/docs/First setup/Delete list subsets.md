[List subsets](https://help.anaplan.com/list-subsets-589d9f5d-f439-40a4-905f-5027c2dc9c21 "List subsets")

To delete a list subset:

1. Select **General Lists** in the model settings bar.
2. Select a list, then select **Open**.
3. Select **Subsets** > **Delete**.
4. Select the list subset you want to delete.  
	**Note**: Select **Delete All** to mark all list subsets for deletion, or select **Keep All** to keep all list subsets.
5. Select **OK**.
