English

Don't use emojis or symbols in any naming of lists, modules, line items, or actions. They can cause issues with integrations as well as ALM syncs (even in Functional Areas).

If you're going to use emojis for pages that aren't going to be used in an integration process, ensure the emoji is UTF-8 compliant.
