Users shouldn't have to wonder whether different words, situations, or actions mean the same thing. Use consistent forms (for example, images, naming, words) and colors to communicate.

Define naming conventions, color palettes, etc. for the tenant at the beginning of the project. Name the same elements across different pages with the same name, and keep links to pages and target page names consistent so users aren't confused when moving between pages.

For consistency, place the same information elements in the same spot across pages.

Use consistent colors for the same metrics shown in different places across the Anaplan application.
