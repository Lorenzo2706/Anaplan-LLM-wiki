English

Rename the import sources as soon as possible. For a saved view, include the module name (module.saved view). For model imports, include a shorted version of the model name (model\_module.saved view).

[Naming Convention](https://help.anaplan.com/name-conventions-aeb0b95e-f7a3-4fe5-81c7-aec9a12f80be)

For one-off imports or when import sources are no longer required, delete the sources to keep the source list tidy.

- [5.03-01 Remove unwanted sources](https://support.anaplan.com/remove-unwanted-sources-31ed8f86-f098-4417-8b2b-9651f1a04e2e)
