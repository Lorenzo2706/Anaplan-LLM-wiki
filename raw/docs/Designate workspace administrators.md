If you’re a workspace administrator, you can designate other users to be workspace administrators. Workspace administrators can access more features within models than other users, and they can control access to models and features within models.

Ensure you are in a model within the workspace for which you want the user to be a workspace administrator. Confirm that the user’s name displays in the list in the **Users** pane.

If the user is not a user for the workspace, [add the user to the workspace](https://help.anaplan.com/37eebabd-4fb5-4b4e-9198-a43c8e2afbca).

**Note:** To prevent you from being locked out, it's not possible to remove the workspace administrator privilege from your own user.

To designate a user as a workspace administrator:

1. Go to **Model Settings >** **Users**.
2. Select the user name and click the **Workspace Administrator** checkbox.

The user now has [workspace administrator level access](https://help.anaplan.com/44fec486-243d-4980-b7ae-60c7ab84f4c9) for this workspace.

Also see " [When integrations require workspace administrator privileges](https://community.anaplan.com/discussion/154759/do-your-integrations-require-workspace-administrator-privileges/p1?new=1) ."
